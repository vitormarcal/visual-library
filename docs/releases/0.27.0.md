# Visual Library 0.27.0

Consulta de existência de imagens antes da seleção em aplicações integradas.

- Novo `POST /api/assets/lookup`: recebe de 1 a 100 hashes SHA-256 e retorna existência e ID do asset na mesma ordem das entradas.
- Aceita sessão do dono ou token Bearer de aplicação, incluindo imagens ocultas e de qualquer origem. Não altera arquivos, tags ou referências.
- Usa o índice de hashes existente; sem dependências ou migração. Registros antigos sem hash não são encontrados.
- Contrato e fluxo de integração documentados em [API de assets](../assets-api.md). A integração no Media Pulse fica para sua própria entrega.

Validação: 92 testes aprovados e build Nuxt de produção concluído.
