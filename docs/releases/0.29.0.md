# 0.29.0

Biblioteca com carregamento em lotes de 60 imagens, busca e filtros no servidor, seleção global e restauração da posição de navegação. Pastas, Explorar e imagens relacionadas carregam apenas os dados necessários.

Respostas do catálogo usam compressão gzip. O visualizador mantém a prévia durante o carregamento do original e permite tentar novamente em caso de erro. Imagens privadas usam cache com revalidação autenticada.

Validação local: 97 testes passaram, build concluído e fluxos de navegador verificados com acervo sintético de 3.000 imagens. O typecheck geral ainda apresenta erros preexistentes. Resultados e limites estão no [relatório de implementação](../performance/2026-11-11-asset-loading-implementation.md).

Esta versão registra as alterações no código; publicação de imagem e atualização de produção ainda pendentes.
