# Movimentos vinculados às obras do Media Pulse

Aprovado na conversa: obras aceitam vários movimentos; corrigir a obra atualiza automaticamente suas imagens centralizadas. Preservar tags pessoais, referências de outras obras e as oito tags por imagem. Falhas não impedem salvar dados no Media Pulse e permitem nova tentativa.

Adicionar atualização de um grupo de tags por referência existente, com procedência. Edição pessoal continua disponível. Tags antigas sem procedência são preservadas; a API informa a preservação para revisão. Sem curadoria automática, novas telas, autenticação, filas ou sincronização de metadados gerais.

Aceite: substituição de movimentos, assets compartilhados, preservação da edição pessoal, limite explícito sem descarte, idempotência e rejeição de revisões antigas.
